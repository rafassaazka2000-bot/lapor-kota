**lapor-kota**   adalah platform pengaduan masyarakat berbasis web yang dirancang untuk memudahkan warga dalam melaporkan berbagai masalah infrastruktur dan fasilitas publik di lingkungan perkotaan secara cepat dan transparan.
tech stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Styling:** Custom CSS Styling
* **Deployment:** GitHub Pages / Static Hosting
Cara Menjalankan Project
Ikuti langkah-langkah di bawah ini untuk menjalankan project secara lokal di komputer Anda:
 **Clone repository ini**
   ```bash
   git clone [https://github.com/rafassaazka2000-bot/lapor-kota.git](https://github.com/rafassaazka2000-bot/lapor-kota.git)

Bash
cd lapor-kota

Bash
npm install

Bash
npm run dev

jalankan project
Cukup buka file index.html langsung di browser Anda, atau gunakan Live Server di Visual Studio Code.
